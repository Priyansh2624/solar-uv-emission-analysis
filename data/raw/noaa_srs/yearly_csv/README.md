# Yearly NOAA SRS CSV Files

This folder contains yearly CSV files generated from the daily NOAA Solar Region Summary (SRS) records for 2014–2025.

Each CSV contains the active-region information extracted from the SRS files for its corresponding year. The original daily records are stored in the ZIP archive in the parent `noaa_srs/` folder.

Source: [NOAA Solar Region Summary](https://www.swpc.noaa.gov/products/solar-region-summary)
