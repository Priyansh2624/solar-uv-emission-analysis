# Data

This directory contains the observational datasets and processed data used in the Solar UV Emission Analysis project.

## Data Sources

- **NOAA Solar Region Summary (SRS):** Active region information and magnetic classifications.
- **SDO/HMI SHARP:** Solar magnetic field observations and bitmap data.
- **SDO/AIA 1600 Å:** Ultraviolet observations of solar active regions.

## Directory Structure

- `raw/`: Original observational datasets.
- `processed/`: Processed data generated during the analysis.
- `manifests/`: Observation metadata and download records.

## Observation Period

2014–2024.

## Data Management

Large FITS datasets are maintained locally and excluded from GitHub. Relevant metadata, manifests and processed CSV files may be included in this repository.
